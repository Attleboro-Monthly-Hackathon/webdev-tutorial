Box model

Every element is a rectangle: content, padding, border, margin.

Padding adds space inside the border; margin pushes siblings away. The live box sits in the dashed demo below.

.demo-box {
  width: 12rem;
  padding: 1rem;
  border: 4px solid #334155;
  margin: 1rem 0;
  background: #e0f2fe;
}
