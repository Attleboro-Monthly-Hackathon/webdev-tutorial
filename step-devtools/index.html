Chrome DevTools in five minutes

Every major browser ships developer tools. These examples say “Chrome,” but Firefox and Edge have the same ideas with slightly different names.

Opening the tools

  • Inspect a specific thing: right‑click an element → Inspect. DevTools opens focused on that node in the Elements tree.
  • Keyboard: Ctrl+Shift+I (Linux/Windows) or Cmd+Option+I (macOS).

Panels you will use first

Elements — HTML tree on the left, CSS rules on the right. Toggle properties on and off, edit values, and see changes instantly (until you refresh).

Console — JavaScript logs and errors appear here. Some lessons ask you to read a message after running a script.

Network — Lists every file the page loads. Useful when fetch fails or an image path is wrong.

Sources — Lets you set breakpoints and step through JavaScript. Advanced, but good to know it exists.

Inspect this demo

This paragraph uses an inline style for color. In Elements, select it and watch the style attribute in the tree.

Nested box — try changing its background in the Styles pane.

Select the yellow inner box in the Elements tree. In the Styles sidebar, click a color swatch next to background and pick another color. This is the fastest way to experiment before you copy values back into your editor.
