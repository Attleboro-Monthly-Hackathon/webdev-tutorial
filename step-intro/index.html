Start here: what “making a website” actually means

This ring assumes no prior technical background. You only need a normal computer and patience.

Programs and files

Everything you save on your computer is a file. A file has a name and usually an extension after a dot, such as notes.txt or vacation.jpg. The extension hints at the kind of data inside.

A folder (or directory) is a container for files. The tutorial you are reading is a folder of small web “lessons,” each in its own subfolder.

Text editor, not a word processor

When you write code or HTML, you use a text editor—an app that saves plain text. Plain text means no hidden bold, fonts, or colors in the file itself (only what the markup describes).

Word processors like Microsoft Word or Google Docs add their own formatting layers. They are the wrong tool for web files. Good free editors include Visual Studio Code, Zed, Kate, Notepad++ (Windows), or even the simple “Notepad” on Windows in a pinch.

Create a new file, type a few characters, and use “Save as” to name it with an .html extension. Then you can open that file in a browser to see the result.

How a browser fits in

A browser (Chrome, Firefox, Edge, Safari…) reads your HTML file, builds an internal tree of elements called the DOM, paints the page, and runs JavaScript if you include any. The next lessons add detail; for now, think: editor writes text → browser shows a page.
