Inline CSS

The style attribute sets CSS on one element. Quick for demos; avoid for whole sites.

This sentence uses an inline style for color and weight.

You can also place a <style> block in head for rules that stay on one page.

<p style="color:#b45309;font-weight:700;">…</p>
