JavaScript runs in the page

Browsers ship a JS engine. A script tag runs code after the parser reaches it.

Open the console: you should see a greeting logged from the tiny script below.

<script>
  console.log("Hello from the page");
</script>

Inspect this demo

This box marks where the inline <script> sits in the document—inspect it, then scroll to the bottom of <body> in Elements to see the real tag.
