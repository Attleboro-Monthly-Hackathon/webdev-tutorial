HTML building blocks

HTML describes structure and meaning. Browsers combine it with CSS (appearance) and JavaScript (behavior).

Tags, elements, attributes

Most of HTML is written as tags in angle brackets. A matching pair wraps content: <p>…</p> is a paragraph element. Some tags stand alone, like <img …>.

Attributes add details: <a href="../step-01/">Go to lesson 1</a> uses href to give the link destination. id and class are common hooks for CSS and scripts.

Nesting and trees

Elements sit inside other elements, forming a tree. The outer <html> wraps <head> (metadata) and <body> (visible page). Getting nesting wrong—forgetting a closing tag—can confuse the browser’s parser.
