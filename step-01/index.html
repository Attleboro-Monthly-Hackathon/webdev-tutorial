Your first HTML

Every page is a tree of nested elements. Here you only need a handful.

An HTML file is plain text. The browser reads tags such as <p> (paragraph) and shows them as a page.

This lesson uses only the document wrapper (html, head, body), a title for the tab, and p for text.

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <title>Step 1</title>
</head>
<body>
  <p>Hello, web.</p>
</body>
</html>

View source in your browser to see the real tags behind this lesson.

Inspect this demo

Hello, web. This paragraph sits in the dashed frame so Chrome’s Elements tree can focus on it quickly.

Open DevTools (Ctrl+Shift+I or Cmd+Option+I, or right‑click → Inspect), expand #lesson-demo, and hover rows in the tree—the matching part of the page flashes on screen.
