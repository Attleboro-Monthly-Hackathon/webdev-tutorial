Images need alt text

The img element embeds a picture. alt describes it when the image cannot load or for assistive tech.

Local file in this lesson folder—the live image is inside the dashed demo below.

<img src="star.svg" width="72" height="72"
     alt="Blue four-point star">

Prefer CSS for sizing in real projects; width/height here reserve space while the file loads.

Inspect this demo

Inspect the <img> inside #lesson-demo. Verify alt, width, and height in the DOM—if the file path breaks, the alt text is what users still hear or see.
