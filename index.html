From HTML to SPA

Twenty-three tiny static sites: three warm‑up lessons (no prior experience assumed), then HTML through a minimal single‑page app. Each lesson ends with a dashed demo box to inspect in Chrome DevTools.

Run from this directory:

python3 -m http.server 8080

Then visit http://localhost:8080/. Each lesson is its own folder. Navigation uses webring.js and webring-config.json.
