Hyperlinks tie the web together

The a (anchor) element uses href to point somewhere else.

Prefer relative paths (../step-02/) so links still work when the site lives in a subdirectory (for example on GitHub Pages). A leading / always means the domain root, which is usually wrong for project sites.
